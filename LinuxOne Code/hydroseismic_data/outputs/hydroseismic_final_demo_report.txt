HYDROSEISMIC: FINAL DEMONSTRATION REPORT
============================================

PROJECT OVERVIEW
HydroSeismic combines selected public USGS earthquake data and
GDACS earthquake/flood events into a normalized incident dataset.
It provides filtering, visualization, data validation, and a
transparent prototype priority calculation.

DEMO STEPS
1. Open the HydroSeismic Jupyter notebook.
2. Run the notebook cells in order.
3. Show the combined incident dataset and its source counts.
4. Filter by source: USGS or GDACS.
5. Filter by event type: earthquake or flood.
6. Filter by calculated priority band.
7. Show the location plot and priority distribution chart.
8. Show the final data-quality report.

KEY LIMITATIONS
Priority bands are produced by an experimental heuristic.
They are not official warnings, validated risk estimates,
or predictions of future disasters or impacts.
GDACS alert levels remain separate from calculated priority.
